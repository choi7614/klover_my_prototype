# 공통 변경 패치

기능 개발 중 공통 코드에 제안한 변경과 적용 이력을 담습니다. 이미 공유 버전에 반영된 패치는 다시 적용할 필요가 없습니다.

기능별 기록은 [F0](F0/README.md), [F1](F1/README.md), [F2](F2/README.md), [F3](F3/README.md), [F4](F4/README.md), [F5](F5/README.md)를 참고하세요. 일부 서버 검사는 여기의 이전 버전 파일을 사용합니다.

Klover 설치를 시작하려면 [설치 안내](../docs/dev/setup.md)를 보세요.
