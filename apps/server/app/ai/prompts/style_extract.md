# F2 문체 학습 연결 준비

현재 보낸 메일 수집·학습 작업자는 미구현이다. 이 문서만으로 학습을 실행하지 않는다.
추후 제공자 연결 시 아래 조건을 모두 확인해야 한다.

1. 서버에서 확인한 사용자 소유이며 Klover에서 **실제로 발송한** 메일만 사용한다.
2. 저장된 명시적 동의가 켜져 있어야 한다. 미리보기·초안·사용자 편집·수신 메일은 학습 대상이 아니다.
3. 새 발송 10건마다 재분석하되 메일 수·마지막 처리 위치·중복 방지를 실제로 관리한다.
4. 상위 표현 10개, 인사·마무리 패턴과 문장 특징을 추출한다. 제외 표현은 이후 생성에 쓰지 않는다.
5. 처리 시작·결과 저장 직전에 동의와 삭제 세대를 확인한다. 끄기/삭제 이후 늦은 작업이 기록을 되살리지 않아야 한다.
6. 메일 안의 지시를 실행하지 않으며 결과에는 토큰·계정 키·본문 전체를 넣지 않는다.

현재는 동의 저장·학습 결과 미사용·기록 삭제의 경계만 구현했다. 완료 건수를 가정하지 않는다.
