# 기간 선택 과거 메일 가져오기

## 통합 개발: 로컬 정책·재시도·과거 메일 (2026-11-24)

- 자동 프로필 미리보기는 서버에서 로컬로 고정한다. 수동 초안·검색·보고서만 Claude를 선택한다.
- 새 설정은 로컬 전용 모드가 기본이다. 기존 암호화 설정에 모드가 없으면 기존 선택을 보존해 hybrid로 읽는다.
- 로컬 전용은 저장 기본값·명시적 Claude 요청·연결 검사·저장 정책을 읽는 CLI까지 차단한다. 기존 키는 보존한다.
- Claude 제공자 오류·시간 초과 시 로컬로 1회 전환한다. 거절·사용자 취소·미동의·정책 차단은 전환하지 않는다.
  검색은 전환 이후 남은 단계도 로컬을 사용한다. 로컬에서 Claude로는 자동 전환하지 않는다.
- 생성 제한 안에서 Claude 최대 45초·로컬 최대 65초를 배분한다(미리보기의 기존 30초 전체 제한 유지).
  근거/형식 검증은 유지한다. 성공 결과에 실제 처리 AI와 전환 이유를 표시하고 초안·보고서 저장에도 남긴다.
- 과거 메일은 `/settings/mail-history`에서 기간을 선택하고 확인 후 시작한다. 현재 Gmail INBOX만 대상이며
  보낸 메일·보관함·스팸은 제외한다. 한국 날짜 양끝 포함, 최대 366일·작업당 10,000건·1000페이지다.
- 작업은 25건 페이지와 메일별 체크포인트를 DB에 저장한다. 부분 저장·중단·수동 재개·실패를 구분한다.
  서버 재시작 시 running은 paused로 복구한다. 중단 뒤 늦은 이전 작업 응답은 새 실행 번호와 비교해 저장하지 않는다.
  Gmail 페이지 만료 후 재시도는 처음부터 중복 방지 재조회하며, 확인 건수는 재조회한 중복도 포함한다.
- 일반 수신 시작 시점·커서는 바꾸지 않는다. 가져온 메일만 `history_imported`로 표시해 메일함·분석·검색·보고·제안
  조회에서 허용한다. 수집 즉시 로컬 분석을 요청하며, 분석 미완료 보고 입력은 기존처럼 오류로 알린다.
- 새 DB 이력은 `0008_history`(부모 `0007_f1`)다. 기존 메일은 false로 유지하고 가져오기 작업 테이블만 추가한다.
- 이 구현은 합성·분리 DB 검사 대상이다. 실제 Gmail·Ollama·Claude·macOS/Windows 전체 흐름 성공을 뜻하지 않는다.
  기능별 확인과 맥북 업데이트는 [통합 실행 안내](../../dev/local-ai-history-run.md)를 따른다.
