PR #37이 `develop f498d27`에 병합되어 있다. 미커밋·승인 대기가 아니다. 설정·사용·요금·실환경 확인 절차는 [설치·실행 안내](setup.md)를 따른다.

## 현재 동작과 개발 예정 구분

- 기본 AI는 로컬. 자동 F1·임베딩·F5는 로컬만 주입하며 F2/F3/F4는 기본값 또는 요청별 선택을 쓴다.
- Claude 키·모델·최초 전송 동의는 앱 설정에서 입력하고 현재 서버에 암호화 저장한다. API 요금은 구독과 별도다.
- 프로필 자동 미리보기는 답장 기본값을 따른다. Claude 기본값·동의가 있으면 버튼 없이 프로필을 전송할 수 있다.
- 현재 Claude 실패는 오류로 끝난다. 형식 오류 보정·동일 제공자 재시도는 로컬 대체 재시도가 아니다.
- Claude 실패 시 로컬로 한 번 자동 재시도, 로컬 전용 모드에서 Claude 선택·호출·연결 검사 차단은 **개발 예정·미구현**이다.
- 실제 모델 ID의 사용 가능성·비용·품질·속도는 계정과 환경에서 별도 확인해야 한다.

자동 검사/실환경 미검증 근거는 [이번 검증](verification-2026-11-24.md), 남은 개발은 [통합 전달 사항](integration-followups.md)을 본다.
